Maganor Mini — Digital Safety Data Processor

Overview

Maganor Mini is a Python data-processing project designed to demonstrate how fictional or anonymized online-harassment reports can be cleaned, validated, analyzed, and summarized.

Features

- Data processing with Pandas
- Numerical analysis with NumPy
- Reusable data-cleaning functions
- Duplicate detection and removal
- Severity-value validation
- Automated tests using Python assertions
- CSV export

Technologies

- Python
- Pandas
- NumPy
- Jupyter Notebook

How to Run

1. Create and activate a Python virtual environment.
2. Install dependencies using "python -m pip install -r requirements.txt".
3. Open "maganor_data_processor.ipynb" in VS Code.
4. Select the project's Python kernel and run the notebook cells in order.

Privacy and Limitations

This project is a learning prototype that uses fictional or anonymized data. Severity values are illustrative and do not determine real-world danger or replace professional safety assessments.

Learning Goals

The project demonstrates data cleaning, reusable functions, numerical analysis, testing, and data export.
